# รูปแบบผลลัพธ์ที่ต้องการ (Expected Output Format)

เมื่อคำนวณปริมาณสารเคมีเสร็จสิ้น กรุณาแสดงผลลัพธ์ให้ผู้ใช้เห็นในรูปแบบตาราง Markdown ดังต่อไปนี้:

### 📊 สรุปผลการคำนวณสารเคมี

**ข้อมูลตั้งต้น:**
- **สารเคมีที่ใช้:** [ชื่อสารเคมี เช่น เดลตาไซด์]
- **ประเภทการพ่น:** [พ่นหมอกควัน / ULV]
- **จำนวนบ้านที่ต้องพ่น:** [จำนวน] หลัง (เทียบเท่าพื้นที่ [จำนวน x 100] ตารางเมตร)
- **อัตราส่วนผสม:** 1 : [ตัวผสม S] ([สารเคมี] : [น้ำมันดีเซล หรือ น้ำ])
- **อัตราการฉีดพ่น (RA):** [ปริมาณ] ลิตร ต่อพื้นที่ [1,000 หรือ 10,000] ตารางเมตร

**ตารางสารเคมีที่ต้องเตรียม:**

| รายการ | ปริมาณ (ซีซี / มิลลิลิตร) | ปริมาณ (ลิตร) |
| :--- | :---: | :---: |
| 🧪 **สารเคมีชนิดเข้มข้น** | `XXX.XX` | `X.XXX` |
| 🛢️ **ตัวทำละลาย (น้ำ/น้ำมัน)** | `XXX.XX` | `X.XXX` |
| **รวมสารผสมทั้งหมด (Total)** | `XXX.XX` | `X.XXX` |

*หมายเหตุ: ตัวเลขปริมาณให้จุดทศนิยม 2 ตำแหน่งสำหรับ ซีซี และ 3 ตำแหน่งสำหรับ ลิตร*
