# Chemical Calculation Skill

## 🎯 วัตถุประสงค์ (Objective)
Skill นี้ออกแบบมาเพื่อจัดเตรียมวิธีและสูตรสำหรับการคำนวณปริมาณสารเคมีควบคุมยุงลาย (เช่น เดลตาไซด์, ซับมาริน) โดยอ้างอิงตามคู่มือที่กำหนดในโฟลเดอร์ `เอกสาร/`

## ⚙️ กฎสำคัญ: อย่าคำนวณเลขเอง
การคำนวณปริมาณสารเคมี **ห้าม AI คำนวณเองจากกฎด้านล่าง** — เพราะตัวเลขจะถูกต้องเสมอ 100% เมื่อเรียก **deterministic engine** (`src/lib/calculations.ts` → `calculate()`):

- ในแอปนี้ ระบบใช้ `calculate()` ซึ่งรับพารามิเตอร์ `C, S, RA, RA_unit, mix_type, A0, A_house, N, targetVolume, tankCapacity` และคืน `V_total, V_C, V_S, V_per_house, V_C_1L, V_S_1L, tanksCount` เป็นต้น
- เมื่อถูกถามเรื่องการคำนวณ ให้ใช้ **MCP tool `calculate_formula`** (ใน `src/lib/ai/tools.ts`) ซึ่งเรียก engine เดียวกับที่แอปใช้ แล้วตอบด้วยผลจาก tool
- กฎในไฟล์ `เอกสาร/*.txt` ใช้สำหรับ **แปลงฉลาก → พารามิเตอร์** (อ่านค่า C, S, RA, RA_unit จากฉลาก) เท่านั้น ไม่ใช่สำหรับคำนวณเลข

## 📚 ฐานข้อมูลอ้างอิง (Knowledge Base)
เมื่อผู้ใช้ออกคำสั่งเกี่ยวกับการคำนวณสารเคมี ให้ Agent ดึงข้อมูลจากไฟล์ต่อไปนี้เป็นหลัก:
1. `เอกสาร/คำนวณสารเคมี.txt` - สำหรับสูตรสารเดลตาไซด์
2. `เอกสาร/คำนวณสารเคมีซับมาริน.txt` - สำหรับสูตรสารซับมาริน

**กฎการแปลงฉลาก → พารามิเตอร์ (General Rules):**
1. พื้นที่ 1 หลัง (มาตรฐาน) = 100 ตารางเมตร (ค่า default `A_house=100`)
2. พื้นที่รวมสำหรับพ่น = จำนวนหลัง (N) × 100 ตารางเมตร
3. ตัวแปร S (ปริมาณตัวผสม) = อัตราส่วนผสมของน้ำ/น้ำมัน ต่อสารเคมี 1 ส่วน (เช่น 1:79 หมายถึง S=79)
4. ตัวแปร RA (อัตราการไหล หรือ Rate of Application) = ปริมาณสารผสมรวมที่ใช้ต่อ 1,000 ตารางเมตร (หรือตามที่ระบุในฉลาก) พร้อม `RA_unit` (`L` หรือ `cc`)
5. `mix_type`: 2 = "แบบผสมกับ" (เติมสารทบน้ำมัน/ตัวทำละลาย — วิธี ULV), 1 = "แบบผสมให้ได้" (รวมปริมาตรคงที่ — วิธีหมอกควัน)

**ตัวอย่างการแปลงฉลาก:**
- "เดลตาไซด์ 1 ลิตร ผสมน้ำมันดีเซล 79 ลิตร ฉีดพ่นอัตรา 1 ลิตร ต่อ 1,000 ตร.ม." → `C=1, S=79, RA=1, RA_unit='L', A0=1000, mix_type=1`
- "เดลตาไซด์ ULV 1 ลิตร ผสมน้ำมัน 4 ลิตร ฉีดอัตรา 75 มล. ต่อ 1,000 ตร.ม." → `C=1, S=4, RA=75, RA_unit='cc', A0=1000, mix_type=2`
