# Chemical Calculation Skill

## 🎯 วัตถุประสงค์ (Objective)
Skill นี้ออกแบบมาเพื่อจัดเตรียมวิธีและสูตรสำหรับการคำนวณปริมาณสารเคมีควบคุมยุงลาย (เช่น เดลตาไซด์, ซับมาริน) โดยอ้างอิงตามคู่มือที่กำหนดในโฟลเดอร์ `เอกสาร/`

## 📚 ฐานข้อมูลอ้างอิง (Knowledge Base)
เมื่อผู้ใช้ออกคำสั่งเกี่ยวกับการคำนวณสารเคมี ให้ Agent ดึงข้อมูลจากไฟล์ต่อไปนี้เป็นหลัก:
1. `เอกสาร/คำนวณสารเคมี.txt` - สำหรับสูตรสารเดลตาไซด์
2. `เอกสาร/คำนวณสารเคมีซับมาริน.txt` - สำหรับสูตรสารซับมาริน

**กฎการคำนวณเบื้องต้น (General Rules):**
1. พื้นที่ 1 หลัง (มาตรฐาน) = 100 ตารางเมตร
2. พื้นที่รวมสำหรับพ่น = จำนวนหลัง (N) × 100 ตารางเมตร
3. ตัวแปร S (ปริมาณตัวผสม) = อัตราส่วนผสมของน้ำ/น้ำมัน ต่อสารเคมี 1 ส่วน (เช่น 1:79 หมายถึง S=79)
4. ตัวแปร RA (อัตราการไหล หรือ Rate of Application) = ปริมาณสารผสมรวมที่ใช้ต่อ 1,000 ตารางเมตร (หรือตามที่ระบุในฉลาก) 

## 📝 วิธีตอบกลับ (Output Format)
เมื่อทำการคำนวณเสร็จสิ้นแล้ว Agent จะต้องจัดรูปแบบผลลัพธ์การคำนวณตามที่ระบุไว้ในไฟล์:
`เอกสาร/webresult/resulttowant.md`

ห้ามตอบกลับด้วยรูปแบบอื่นที่นอกเหนือจากการสรุปผลตาม `resulttowant.md` อย่างเด็ดขาด
